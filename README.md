## Organisation

```
bible/        Bible de Vivelande (canon) : monde, personnages, lieux, factions, glossaire, style
romans/       Un dossier par roman : roman.yaml, plan.md, chapitres/, illustrations/, notes/
app/          Liseuse web installable (téléphone, tablette, ordinateur, hors-ligne)
outils/       Scripts de vérification (en-têtes, liens, images)
suivi/        Journal des sessions des agents et questions ouvertes
AGENTS.md     Règles pour tous les agents (Claude, ChatGPT…)
```

## Travailler avec des agents

Les règles sont dans [AGENTS.md](AGENTS.md) (lu par ChatGPT/Codex) ; [CLAUDE.md](CLAUDE.md) l'importe.
Chaque agent travaille sur sa propre branche et propose ses changements en pull request.
