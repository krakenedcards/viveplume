# Journal des sessions

**Un fichier par session**, jamais de modification des entrées des autres :
deux agents peuvent ainsi journaliser en même temps sans conflit.

Nom du fichier : `AAAA-MM-JJ-agent-sujet.md` (ex. `2026-11-28-chatgpt-vivepierre-ch01.md`).

Contenu :

```
# AAAA-MM-JJ — agent (claude | chatgpt) — branche
- Fait : …
- Ajouté à la bible : …
- Reste à faire / questions : …
```
